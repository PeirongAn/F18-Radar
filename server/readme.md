   - 实现了雷达扫描更新、目标跟踪和显示更新逻辑
   - 使用FuncAnimation实现动画效果
   - 包含以下可视化元素：
     - 距离环
     - 扫描线
     - 目标标记（三角形，带航向）

     - 历史轨迹点
     - 雷达噪点效果
     - 状态栏信息显示
