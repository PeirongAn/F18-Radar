# 雷达系统数据统计说明

## 1. 概述
根据 `radar_operations.db` 中的数据，生成统计数据，分别包含传感器任务和威胁排序任务。

## 2. 传感器任务统计 (sensor_task_statistics 表)

### 2.1 统计字段
包含以下字段：
- 用户名 (user_id)
- 任务ID (task_id) 
- 是否启用AI (is_ai_active)
- AI等级 (ai_level)
- 难度等级 (difficulty_level)
- 是否开启音频 (audio_enabled)
- 重复序号 (repetition_count)
- 雷达初始参数设置时间 (radar_settings_time)
- 雷达天线设置时间 (antenna_settings_time)
- 目标选择完成时间 (target_selection_time)
- 任务整体完成时间 (total_task_time)
- 是否正确 (is_correct)
- 选择方式 (selection_method) - 人工选择还是AI选择
- 任务设置详情 (task_settings_detail)

### 2.2 计算规则

#### 基础信息字段
- **用户名**: `user_operations` 表的 `user_id` 列
- **任务ID**: `user_operations` 表的 `task_id` 列
- **是否启用AI**: `task_settings` 表的 `is_ai_active` 列
- **AI等级**: `task_settings` 表的 `ai_level_name` 列
- **难度等级**: `task_settings` 表的 `difficulty_name` 列
- **是否开启音频**: `task_settings` 表的 `audio_enabled` 列

#### 重复序号计算规则
监控 `operation_type` 为 `task_start`, `settings_update`, `antenna_adjusted`, `target_selected` 的操作。

比较规则：提取 `task_settings` 表中的设置信息（排除 `id` 和 `task_id`）：
- `user_id`
- `is_ai_active`
- `ai_level_name`
- `difficulty_name`
- `audio_enabled`

如果当前记录的设置与上条记录的设置完全一致，则重复序号+1，否则重新从1开始计数。

#### 时间计算规则
- **雷达初始参数设置时间**: `settings_update` 操作的 `timestamp - receive_timestamp`
- **雷达天线设置时间**: `antenna_adjusted` 操作的 `timestamp - receive_timestamp`
- **目标选择完成时间**: `target_selected` 操作的 `timestamp - receive_timestamp`
- **任务整体完成时间**: 同一 `task_id` 中，`target_selected` 的 `timestamp` 减去 `task_start` 的 `timestamp`

#### 结果字段
- **是否正确**: `target_selected` 操作时的 `is_correct` 值
- **选择方式**: `target_selected` 操作时的 `event_owner` 值（人工/AI）

## 3. 威胁排序任务统计 (threat_task_statistics 表)

### 3.1 统计字段
包含以下字段：
- 用户名 (user_id)
- 任务ID (task_id)
- 是否启用AI (is_ai_active)
- AI等级 (ai_level)
- 难度等级 (difficulty_level)
- 是否开启音频 (audio_enabled)
- 重复序号 (repetition_count)
- 威胁项选择时间 (threat_selection_time)
- 任务整体完成时间 (total_task_time)
- 是否正确 (is_correct)
- 选择方式 (selection_method) - 人工选择还是AI选择
- 任务设置详情 (task_settings_detail)

### 3.2 计算规则

#### 基础信息字段
与传感器任务相同，从 `task_settings` 表获取。

#### 重复序号计算规则
监控 `operation_type` 为 `SwitchSA`, `ResetSA`, `threat_clicked` 的操作。

比较规则与传感器任务相同，使用相同的设置信息进行比较。

#### 时间计算规则
- **威胁项选择时间**: `threat_clicked` 操作的 `timestamp - receive_timestamp`
- **任务整体完成时间**: 同一 `task_id` 中，`threat_clicked` 的 `timestamp` 减去 `SwitchSA` 或 `ResetSA` 的 `timestamp`

#### 结果字段
- **是否正确**: `threat_clicked` 操作时的 `is_correct` 值
- **选择方式**: `threat_clicked` 操作时的 `event_owner` 值（人工/AI）

## 4. 数据库表结构

### 4.1 传感器任务统计表 (sensor_task_statistics)
```sql
CREATE TABLE sensor_task_statistics (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id TEXT,
    task_id INTEGER,
    is_ai_active BOOLEAN,
    ai_level TEXT,
    difficulty_level TEXT,
    audio_enabled BOOLEAN,
    repetition_count INTEGER,
    radar_settings_time INTEGER,
    antenna_settings_time INTEGER,
    target_selection_time INTEGER,
    total_task_time INTEGER,
    is_correct TEXT,
    selection_method TEXT,
    task_settings_detail TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
)
```

### 4.2 威胁任务统计表 (threat_task_statistics)
```sql
CREATE TABLE threat_task_statistics (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id TEXT,
    task_id INTEGER,
    is_ai_active BOOLEAN,
    ai_level TEXT,
    difficulty_level TEXT,
    audio_enabled BOOLEAN,
    repetition_count INTEGER,
    threat_selection_time INTEGER,
    total_task_time INTEGER,
    is_correct TEXT,
    selection_method TEXT,
    task_settings_detail TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
)
```

## 5. 使用说明

运行统计脚本：
```bash
cd server
python data_statistics.py
```

脚本会自动：
1. 连接数据库
2. 创建统计表（如果不存在）
3. 清空现有统计数据
4. 生成新的统计数据
5. 保存到数据库
