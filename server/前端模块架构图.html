📊 数据流向说明

1. 用户交互: 用户操作 → 组件事件 → Hook处理 → Store更新 → 组件重渲染
2. 服务器通信: WebSocket → useRadarData → Store状态 → 组件显示
3. AI决策: AgentStore → 自动操作 → 消息发送 → 服务器响应
4. 视图切换: App.tsx 控制 → 组件卸载/挂载 → 状态重置
