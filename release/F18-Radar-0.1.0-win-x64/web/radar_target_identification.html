雷达目标敌我自动识别策略

在雷达初次探测到一批未知目标时，为了能够快速评估战场态势，系统会执行一套自动的敌我识别程序。该程序的核心是为每个未知目标计算一个 “威胁分数” (Threat Score)，并以此作为判定的主要依据。

核心评估维度

威胁分数的计算是动态且复杂的，它综合了两个关键维度：目标的距离和飞行航向。

1. 距离分数 (Distance Score)

这是一个非常直观的指标：目标离我机越近，其潜在威胁就越大。距离分数是一个归一化的值（0到1之间），距离越近，分数越高。

2. 航向分数 (Heading Score)

这个维度评估的是目标的飞行意图，采用连续变化的威胁评估模型。系统基于目标的绝对航向角度计算威胁分数。

  • 0度（正北方向）：威胁分数最低（-1），表示目标正在远离或处于低威胁状态
  • 180度（正南方向）：威胁分数最高（+1），表示目标处于最高威胁状态
  • 90度和270度（东西方向）：威胁分数为中等（0），表示目标处于中等威胁状态
  • 威胁分数使用余弦函数连续变化：航向分数 = -cos(航向角度)

加权计分与最终判定

系统在综合评估时，为这两个维度分配了不同的重要性权重，以构建一个更全面的威胁模型。

总威胁分数 = (距离分数 * 90%) + (航向分数 * 10%)

这个公式表明，在当前策略下，我们认为目标的 距离依然是最重要的因素，但其飞行航向的威胁程度也占有相当大的比重。航向评分采用连续变化模型，能够更精确地反映不同方向的威胁水平。

连续威胁评估模型

新的航向评分系统摒弃了传统的分段评分方式，采用数学函数实现威胁值的平滑过渡：

航向分数 = -cos(航向角度)

这种连续变化的模型具有以下优势：

  • 平滑过渡：威胁值在-1到+1之间连续变化，避免了突变
  • 对称性：东西方向（90°/270°）威胁值相等，符合战术逻辑
  • 极值明确：正北（0°）威胁最小，正南（180°）威胁最大
  • 数学稳定：基于余弦函数，计算结果稳定可靠

最终识别规则

在计算出所有未知目标的"总威胁分数"后，系统会将它们从高到低进行排序。

最终，得分最高的2个目标将被自动识别为"敌机"(Enemy/Army)，并以相应的符号在雷达上标出。其余所有目标则被识别为"友机"(Friend)。
