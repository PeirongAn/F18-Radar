F18 Radar Windows x64 测试包
============================

启动：双击“启动F18雷达系统.cmd”。服务准备好后会自动打开浏览器。
地址：http://127.0.0.1:8080/
停止：关闭服务控制台，或在控制台按 Ctrl+C。

目录说明：
- runtime：Python 3.10 后端及原生依赖，不要拆分或移动内部文件。
- web：前端静态文件和运行配置。
- config\portable.env：设备与服务环境配置。
- data：运行数据库、眼动和生理数据。
- logs：服务日志。

测试建议：
1. 首先在没有 Tobii/手环设备时启动，确认主页面和任务流程可进入。
2. 连接设备后重新启动，再检查眼动、生理状态页和数据落盘。
3. 如 8080 端口被占用，请先关闭占用该端口的旧服务。

注意：
- 不要把 data 目录中的正式实验数据通过普通聊天或公共网盘发送。
- 删除或覆盖测试包前，请先备份 data 目录。
