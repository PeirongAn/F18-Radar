# JF-17 HUD 符号与数字说明草稿

本文档基于用户提供的 HUD 截图整理，用于解释图中数字、字母和符号的大致含义。  
说明依据为公开 JF-17/DCS HUD 资料与通用 HUD 显示规则，不等同于官方座舱手册。无法从截图单独确认的缩写，本文以“可能/待确认”标注。

## 总体结构

这张图应理解为同一个 HUD 视场中的投影符号层，而不是平台控制和武器发射两套独立界面。

- 共享基础层：速度、高度、航向、姿态、飞行路径标记、基础状态。
- 平台控制时机叠加：航路点、路径引导、控制权、导航保持、姿态/航向修正提示。
- 武器发射时机叠加：目标框、投放/发射参考线、瞄准提示、武器状态、发射抑制/允许状态。

## 顶部区域

| 显示 | 位置 | 含义 |
|---|---|---|
| `038` | 顶部中央框 | 当前航向，约 038 度。 |
| `03` / `05` / `2` | 顶部航向带周围 | 航向带刻度，用于表示相邻航向。 |
| 顶部小刻度 | `038` 下方横向刻度 | 航向刻度带。 |
| 左右 `10` 与弧线 | 顶部两侧 | 滚转/坡度参考刻度，用于判断机体左右倾斜。 |

## 中央飞行与姿态区域

| 显示 | 含义 |
|---|---|
| 倾斜长线 | 地平线/姿态基准线。线条倾斜说明飞机存在滚转角。 |
| 中央小圆加左右短线 | 飞行路径标记，表示飞机实际运动方向，不完全等同于机头指向。 |
| 中央十字 | 机体/准星/参考中心，具体含义取决于 HUD 模式。 |
| 中央左右括号/箭头 | 航向、路径修正、目标指示或瞄准参考符号。 |
| 下方两个亮点与放射短线 | 可能是目标、传感器或武器相关提示，更偏向武器发射/目标指示叠加层。 |

## 设计结论

后续界面设计应按以下原则处理：

1. HUD 是一个共享投影视场，不要拆成“平台控制 HUD”和“武器发射 HUD”两个独立屏幕。
2. 速度带、高度带、航向带、姿态线、飞行路径标记属于持续存在的基础层。
3. 平台控制任务只是在基础层上增加航路点、路径引导、控制权、导航保持等提示。
4. 武器发射任务只是在基础层上增加目标、投放/发射参考线、瞄准和发射状态等提示。
5. 不确定缩写不要在 UI 文案中强行展开，应先保留原始 HUD 标识，后续根据更明确资料再解释。
